# Online Bookstore

A simple Online Bookstore developed as a Software Engineering Mini Project.

## About

This project is a basic online bookstore system designed to demonstrate software engineering concepts such as requirements analysis, system design, and software testing.

## Features

- Browse available books
- View book details
- Search for books
- Add books to cart
- Place orders

## To Run
```
py -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
py manage.py runserver
```
